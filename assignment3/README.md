
## State Shape

```text
state
├── tasks
│   ├── id
│   ├── title
│   ├── completed
│   ├── priority
│   └── subtasks
│       ├── id
│       ├── title
│       └── completed
│
├── goals
│   ├── id
│   ├── title
│   ├── targetDate
│   ├── progress
│   └── completed
│
└── moodItems
    ├── id
    ├── mood
    ├── note
    └── date
```

## Features Completed

*  Create, edit, and delete tasks.
*  Mark tasks as completed or pending.
*  Add, edit, and remove subtasks.
*  Track long-term goals with progress.
*  Record daily mood entries with optional notes.
*  Persistent state using local storage (if implemented).
*  Responsive user interface.
